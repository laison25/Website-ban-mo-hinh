- Triển khai website bằng PHP thuần, MySQL, HTML, CSS và JavaScript.
- Hoàn thiện các luồng chính của website: sản phẩm, tài khoản, giỏ hàng, yêu thích, checkout, thanh toán demo, lịch sử đơn hàng và quản trị.
- Cập nhật tài liệu README theo các chức năng đang có trong website.
- Cập nhật tài liệu SRS chức năng đăng nhập, bổ sung đăng nhập Google.
- Cập nhật báo cáo tiến độ theo trạng thái mới nhất của dự án.

### 2. Công việc của Lại Nam Sơn
- Xây dựng cấu trúc dự án PHP/MySQL.
- Kết nối database MySQL và tạo dữ liệu mẫu sản phẩm.
- Xây dựng trang chủ hiển thị banner, danh mục và danh sách sản phẩm.
- Xây dựng trang chi tiết sản phẩm.
- Xây dựng tìm kiếm, lọc, sắp xếp và gợi ý tìm kiếm AJAX.
- Xây dựng đăng ký, đăng nhập, đăng xuất và cài đặt tài khoản.
- Bổ sung đăng nhập Google/Facebook và luồng OAuth callback.
- Cập nhật SRS đăng nhập để mô tả đăng nhập thường và đăng nhập Google.
- Xây dựng giỏ hàng, cập nhật số lượng, tính tổng tiền và thêm sản phẩm vào giỏ.
- Xây dựng checkout nhiều phương thức:
  - COD.
  - Chuyển khoản ngân hàng.
  - VietQR.
  - Ví điện tử demo.
  - Thẻ ATM/Visa demo.
- Xây dựng trang thanh toán, xác nhận thanh toán demo, đặt hàng thành công, lịch sử đơn hàng và tra cứu đơn hàng.
- Tích hợp API Box AI tư vấn sản phẩm qua `ai-chat.php`.
- Cấu hình Box AI dùng Gemini API qua `includes/gemini-config.php` và fallback local khi không có API key hoặc API lỗi.
